# JoinHook Local — Release checklist

- [ ] Production build passes lint, audit and browser QA.
- [ ] `/api/local/status` reports core backend ready.
- [ ] First administrator initialized once.
- [ ] Temporary setup token removed or rotated.
- [ ] At least one operator account tested with expected role.
- [ ] Territorial data imported as draft and manually reviewed.
- [ ] Published business renders in `/local`.
- [ ] Geolocation denied path tested.
- [ ] Offline/degraded path tested.
- [ ] Mobile viewport verified without vertical page scroll.
- [ ] Desktop viewport verified without vertical page scroll.
- [ ] Admin and setup routes remain `noindex,nofollow`.
- [ ] Production artifact deployed to hosting and static assets synchronized.
- [ ] Public pilot URL checked from an external network/device.
