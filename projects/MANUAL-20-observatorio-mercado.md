# 20 — Observatorio de mercado

## Propósito
Sistema de observación de tendencias, necesidades, competencia y oportunidades en turismo, comercio y servicios.

## Tecnologías candidatas
1. Ruby on Rails — registro de señales y fuentes.
2. Next.js + TypeScript — dashboard.
3. Django + Python — procesamiento y análisis.
4. Laravel + PHP — alternativa web.

## Mapa
`signals/` señales; `sources/` fuentes; `competitors/` referencias; `trends/` tendencias; `analytics/` análisis; `reports/` informes.

## Principio
Separar datos observados de conclusiones y registrar fecha, fuente y nivel de confianza.
