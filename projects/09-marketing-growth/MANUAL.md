# 09 — Marketing & Growth

## Propósito
Sistema para investigación de mercado, SEO/SEM, contenidos, leads, campañas y crecimiento sostenible de JoinHook y sus productos.

## Tecnologías candidatas
- **Ruby on Rails:** CRM de campañas, workflows y API.
- **Next.js + TypeScript:** dashboards y herramientas web.
- **Django + Python:** analítica, scraping permitido, scoring y pipelines.
- **Laravel + PHP:** alternativa web administrativa.

## Estructura
```text
market/                 # señales y mercado
seo/                    # SEO técnico/contenido
campaigns/              # campañas
content/                # contenidos
leads/                  # captación
analytics/              # métricas
reports/                # informes
```

## Principios
No confundir observación con datos verificados; registrar fuente y fecha; separar cuentas de monitoreo de cuentas de publicación; respetar términos y privacidad.
