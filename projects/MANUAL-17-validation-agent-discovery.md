# 17 — Startup Validation / Agent Discovery

## Propósito
Herramienta para investigar, estructurar, validar y priorizar ideas de negocio mediante hipótesis, experimentos, evidencia y criterios SMART.

## Tecnologías candidatas
1. Ruby on Rails — workflow y registro de hipótesis.
2. Next.js + TypeScript — tablero de experimentos.
3. Django + Python — scoring y análisis.
4. Laravel + PHP — alternativa web.

## Mapa de implementación
`ideas/` ideas; `hypotheses/` hipótesis; `experiments/` experimentos; `interviews/` entrevistas; `evidence/` evidencia; `scoring/` evaluación; `reports/` resultados.

Cada archivo debe registrarse en el `FILE-MAP.md` del proyecto con ruta, propósito, entradas, salidas y dependencias.
