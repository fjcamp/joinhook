# 18 — Turismo & Estacionalidad

## Propósito
Línea de investigación sobre cómo la estacionalidad afecta gestión económica, operacional, laboral y comunitaria del turismo y la hotelería.

## Tecnologías candidatas
1. Ruby on Rails — plataforma de casos y datos.
2. Next.js + TypeScript — visualización y dashboards.
3. Django + Python — análisis estadístico y modelos.
4. Laravel + PHP — portal de investigación.

## Mapa
`research/` estudios; `datasets/` datos; `models/` modelos; `reports/` informes; `visualizations/` gráficos; `sources/` fuentes.

Toda conclusión debe mantener trazabilidad de fuente, periodo y metodología.
