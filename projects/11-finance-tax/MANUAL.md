# 11 — Finance & Tax

## Propósito
Módulo financiero para ingresos, egresos, tesorería, conciliación, reportes y procesos tributarios/integraciones autorizadas.

## Tecnologías candidatas
- Ruby on Rails — dominio financiero y auditoría.
- Next.js + TypeScript — panel y reportes.
- Django + Python — conciliación y analítica.
- Laravel + PHP — alternativa web empresarial.

## Estructura
```text
ledger/; cashflow/; treasury/; reconciliation/; tax/; reports/; audit/
```

## Requisitos críticos
No alterar registros financieros sin trazabilidad. Separar datos de prueba y producción. Secretos y credenciales siempre fuera del repositorio.
