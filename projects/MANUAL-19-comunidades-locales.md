# 19 — Gestión y comunidades locales

## Propósito
Investigar la compatibilidad entre metodologías de administración y formas propias de organización de comunidades locales e indígenas, sin asumir que un modelo empresarial externo sea universal.

## Tecnologías candidatas
1. Ruby on Rails — repositorio de estudios y casos.
2. Next.js + TypeScript — portal documental.
3. Django + Python — análisis cualitativo/cuantitativo.
4. Laravel + PHP — alternativa web.

## Mapa
`research/` investigaciones; `cases/` casos; `sources/` fuentes; `ethics/` criterios; `reports/` resultados.

## Principio
Registrar contexto, metodología, consentimiento cuando corresponda y límites de interpretación.
