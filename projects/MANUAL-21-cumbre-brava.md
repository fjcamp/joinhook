# 21 — Cumbre Brava

## Propósito
Videojuego de aventura independiente inspirado en Chile, montañas, bosques y volcanes. Proyecto personal y separado conceptualmente de JoinHook.

## Tecnologías candidatas
1. **Ruby on Rails** — backend opcional para cuentas, rankings o contenido; no es la ruta principal del juego.
2. **Godot + GDScript** — motor y gameplay recomendado.
3. **Unity + C#** — alternativa para PC/Android.
4. **Unreal Engine + C++/Blueprints** — alternativa de mayor complejidad gráfica.

## Personajes y mundo
Indy; Lili; Kaito; Foxgen. Biomas chilenos, araucarias, volcanes, rutas abiertas, rucas, guardaparques, mochilas y elementos de exploración.

## Mapa
`scenes/` escenas; `scripts/` gameplay; `characters/` personajes; `world/` biomas; `assets/` recursos; `ui/` interfaz; `audio/` audio; `tests/` pruebas; `build/` artefactos locales.

## Objetivos
MVP para Windows `.exe` y Android `.apk`, con respaldo/versionado en GitHub y desarrollo de coste mínimo.
