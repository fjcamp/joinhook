# 12 — Legal & Compliance

## Propósito
Gestionar contratos, cumplimiento, privacidad, documentación laboral/RRHH, controles regulatorios y trazabilidad.

## Tecnologías candidatas
- Ruby on Rails — workflow documental y permisos.
- Next.js + TypeScript — portal y revisión.
- Django + Python — clasificación/document processing controlado.
- Laravel + PHP — alternativa web empresarial.

## Estructura
```text
contracts/; compliance/; privacy/; hr/; policies/; approvals/; audit/
```

## Seguridad
Control de acceso por rol; registros de auditoría; minimización de datos; cifrado cuando corresponda; retención definida; nunca almacenar credenciales en GitHub.
