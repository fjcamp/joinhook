# 15 — Alianzas y Colaboración

## Propósito
Estructura para gestionar futuras alianzas con empresas, instituciones, universidades, municipios y organizaciones colaboradoras.

## Tecnologías candidatas
1. Ruby on Rails — CRM de alianzas y workflows.
2. Next.js + TypeScript — portal y fichas públicas.
3. Django + Python — análisis y scoring.
4. Laravel + PHP — alternativa web.

## Mapa de implementación
`partners/` entidades; `institutions/` instituciones; `agreements/` acuerdos; `opportunities/` oportunidades; `communications/` comunicaciones; `public-content/` contenido autorizado.

## Regla
Una alianza no se publica hasta contar con autorización y datos verificables. Registrar estado, responsable, fecha y evidencia.
